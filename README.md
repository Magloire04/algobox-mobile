# AlgoBox Mobile

Éditeur et interpréteur de pseudo-code compatible avec la syntaxe d'AlgoBox, pensé pour s'utiliser sur téléphone.

- Déclaration des variables (NOMBRE, CHAINE, LISTE)
- Fonction numérique F1(x) et fenêtre graphique
- Éditeur d'algorithme avec boutons d'insertion et indentation automatique
- Exécution complète ou pas à pas, valeurs des variables, tracé de points et de segments
- Import et export du code complet (VARIABLES / DEBUT_ALGORITHME / FIN_ALGORITHME)

## Déploiement

Application statique : un seul fichier `index.html`, sans dépendance ni étape de build.
Il suffit de servir le dossier tel quel (GitHub Pages, Netlify, Nginx, etc.).
